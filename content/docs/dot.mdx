Polkadot is another smart-contract based blockchain with a number of innovations.

Polkadot is one of the first to design a Layer 0, where it's designed to facilitate multiple chains from the offset. The multiple chains, called parachains, act like a Layer 1 smart contract blockchain like Ethereum or BNB Chain.

By being a Layer 0, it provides the following to its parachains:
- cross-chain communication
- shared security
- forkless upgrades
