Before reading about Ethereum, I recommend reading up on Bitcoin first, as it will be referenced.

Ethereum is taking bitcoin and adding the ability to write logic into it, known as Smart Contracts.

This means that instead of just sending and receiving a token, you can also add rules. For example, it is possible to set a rule where if the price of ETH goes to a certain number, the ETH will get automatically transferred to another wallet.

## Proof-of-Work to Proof-of-Stake

Ethereum started with the same security mechanism as Bitcoin, using mining to implement Proof-of-Work, or PoW. PoW consisted of running computers to perform calculations, which would eat up electricity. When more computers are mining, the chance of getting the reward lowers, so even more computers are added, increasing energy costs.

Proof-of-Stake, of PoS, was first introduced and implemented in a protocol called Peercoin back in 2012. PoS requires value to be staked and a random algorithm to choose the which computer will receive the rewards. 

In 2022, Ethereum transitioned from PoW to PoS. Because the computer's goal is now only to keep track of the blockchain and have no requirements for mining, energy consumption dropped by 99%.
