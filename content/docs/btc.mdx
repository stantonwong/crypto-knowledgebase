Bitcoin is what started crypto.

Bitcoin is the first attempt at building a decentralized currency, where any computer with internet can install software that will try to sync with each other to make sure the information is all correct.

Basically, a distributed ledger. This means that the more computers running this program, the safer the ledger, since every single computer is essentially a back up of the data.

## Incentives

To make it worth your while to run the software on your computer, the software created a lottery system where if you are running the softare, there is a chance that you'll win a reward in the form of the distributed token.

To create value around the reward, bitcoin did two things:
- limit the maximum amount of bitcoin that will be created (21 million)
- the reward gets smaller by 50% every 4 years, extending the amount of time that the system will continue to reward bitcoin.

A side effect of the rewards getting smaller is that that inflation will continue to decrease, making the bitcoin that is already out there more valuable.

## Cost to Use

To make a transaction, there will be a network cost to send the tokens. This is paid to the computers that are running the software as additional incentive for maintaining the network.
