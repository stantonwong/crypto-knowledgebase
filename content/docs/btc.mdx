Bitcoin is what started crypto.

Bitcoin is the first attempt at building a decentralized currency, where any computer with internet can install software that will try to sync with each other to make sure the information is all correct.

Basically, a distributed ledger. This means that the more computers running this program, the safer the ledger, since every single computer is essentially a back up of the data.

## Incentives

To make it worth your while to run the software on your computer, the software created a lottery system where if you are running the softare, there is a chance that you'll win a reward in the form of the distributed token.

To create value around the reward, bitcoin did two things:
- limit the maximum amount of bitcoin that will be created (21 million)
- the reward gets smaller by 50% every 4 years, extending the amount of time that the system will continue to reward bitcoin.

A side effect of the rewards getting smaller is that that inflation will continue to decrease, making the bitcoin that is already out there more valuable.

## Cost to Use

To make a transaction, there will be a network cost to send the tokens. This is paid to the computers that are running the software as additional incentive for maintaining the network.

## Mining

With bitcoin, you'll hear a lot about mining. Mining is the term for the computers on the network trying to win the reward. The way it works is that every 10 minutes, there is a new block that is added to the bitcoin blockchain. To add the block, a reward is given out to one of the computers on the network. The computer that wins is the one who is able to be the first one to answer a math problem. To answer the problem quickly, you need processing power, preferably in parallel. This is why so many people were buying up GPUs to try to answer the math problem. The more processing power you have, the higher the chance you will get to earn the block's reward.

The reason it is called mining is because your computer is constantly striking into the dirt, hoping to find that bitcoin reward.

## Projects

Projects on Bitcoin are not quite the same as projects on Ethereum because Bitcoin does not support smart contracts natively, requiring a bit of ingenuity to build on top of.

- Lightning Network (https://lightning.network/)
  - facilitates much faster transactions by running nodes (essentially mini-blockchains) connected to by channels from bitcoin wallets, then updating it into the BTC blockchain (this means the individual transactions are not necessarily recorded on the BTC blockchain, only the final result gets updated)
